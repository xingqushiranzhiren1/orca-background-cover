# orca-background-cover

虎鲸笔记（Orca Note）背景图插件，支持自定义背景图片、预设壁纸、随机切换和透明度调节。

## 功能

- 自定义网络图片 URL 作为背景
- 本地图片上传作为背景
- 预设壁纸（必应每日壁纸、随机风景、随机动漫、Picsum、Unsplash）
- 多图源随机切换，支持启动随机和定时自动切换
- 背景透明度、模糊、位置调节
- 深色/浅色模式独立设置
- 全屏/编辑模式适配

## 安装

1. 下载最新 Release 中的 `orca-background-cover.zip`
2. 解压到虎鲸笔记插件目录
3. 在插件管理中启用

## 开发

```bash
npm install
npm run build
```
